# Contributing

Thanks for your interest in contributing to Awesome Daily!

## Guidelines

- **One game per pull request.** 
- **Add the game to the appropriate category.** If no category fits, feel free to suggest a new one.
- **Use the following format:** `- [Game Name](https://example.com) - Short description of the game.`
- **Keep descriptions concise.** One sentence is ideal.
- **Make sure the game is active, accessible, and high quality.**

## Quality Standards

- The game should be free to play (at least the core experience).
- The game should be web-based or widely available.
- The game should have been active for a reasonable period of time and have at least a small active user base.
